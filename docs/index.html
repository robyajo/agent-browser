The web AI chat you already use, connected to your editor.

Agent Browser is a browser extension and local bridge connecting DeepSeek, Qwen, Claude, and ChatGPT to VS Code and Zed Editor. Describe tasks in plain language, and the AI inspects, edits, and creates files directly in your workspace. No API key needed.

  • Dual Editor: VS Code & Zed Editor
  • Chrome, Edge, Brave (Manifest V3)
  • Linux, macOS, and Windows

One command at a time, visible to you in the chat.

The AI does not get an unrestricted shell. It writes a structured command in its reply, and the extension runs that one tool through the local MCP bridge and returns the result.

  1. You

    Describe a task in your AI chat (e.g. DeepSeek or Qwen).

  2. The AI

    Replies with a tool command prefix, e.g. zededitor/read_file or vscode/read_file.

  3. Extension

    Detects the command and forwards it to the local bridge.

  4. Bridge

    Routes it to the active editor's MCP server.

  5. Chat

    Receives the file contents or edit result, and the AI continues.

Example command format:

{"command":"zededitor/read_file","params":{"path":"README.md"}}

Supported code editors.

Choose between VS Code and Zed Editor. Each editor has 28 workspace tools for complete code reading, editing, and inspection.

VS Code

  • Auto-detects open workspace
  • Commands prefixed with vscode/
  • Read, edit, search, and manage project files
  • Run terminal commands and git operations

Zed Editor

  • Native Assistant integration via OpenAI proxy
  • Commands prefixed with zededitor/
  • Port 17614 reverse proxy for DeepSeek & Qwen
  • Instant chat inside Zed panel without API key

Getting started.

  1. 1. Load the extension

    Clone the repository, open chrome://extensions or edge://extensions, enable Developer mode, and click Load unpacked selecting the agent-browser-extension folder.

  2. 2. Start the bridge

    Run the launcher for your system:

    Linux / macOS
    ./start_zed.sh
    Windows
    start_zed.bat

  3. 3. Configure your editor

    For VS Code, open your project folder. For Zed Editor, add the OpenAI proxy config to settings.json as documented in the README.
